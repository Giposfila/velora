# VÉLORA

Русскоязычный витринный сайт вымышленного бренда одежды. React, TypeScript и Vite. Сборка заранее формирует HTML, а в браузере подключаются поиск, фильтры, корзина и форма подписки.

## Локальный запуск

```sh
npm ci
npm run dev
```

Команда `npm run build` собирает сайт в `dist/`. Команда `npm run preview` запускает предпросмотр сборки.

Корзина и пробная подписка хранятся в браузере. На сайте используются демонстрационные товары и контактный адрес, оформление заказов недоступно.

## GitHub Pages

В настройках репозитория откройте **Settings → Pages → Source** и выберите **GitHub Actions**. Workflow `pages.yml` публикует `dist/` при обновлении ветки `main`. Его также можно запустить вручную во вкладке **Actions**. Путь сайта берётся из настроек Pages.
